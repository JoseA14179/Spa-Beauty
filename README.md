# GlowQueen - Beauty & Skin Care Hero Section

Una recreación responsiva y de alta precisión visual de la sección *Hero* para una landing page de belleza y cuidado de la piel, basada en un diseño de Figma.

## 📌 Características
* **Sin dependencias externas**: Desarrollado utilizando únicamente HTML5 y CSS3 puro.
* **Maquetación con CSS Grid y Flexbox**: Sistema de capas para superponer fondos, vectores e imágenes sin romper el flujo de la página.
* **Efectos y Microinteracciones**: Animaciones CSS en botones, enlaces del menú y tarjetas de testimonios flotantes.
* **Fuentes integradas**: Uso de Google Fonts (`Poppins` y `Open Sans`).

## 🛠️ Tecnologías utilizadas
* HTML5
* CSS3 (Grid, Flexbox, Positioning, CSS Variables)
